# 各平台怎么装

四个平台的**实际做法不一样**，因为底层限制不一样。先说结论：

| 平台 | 怎么装 | 界面 | 能干什么 |
|---|---|---|---|
| **macOS** | `口蘑Mod工坊.dmg` → 拖进「应用程序」 | ImGui 桌面窗口 | 全部功能 |
| **Windows** | 跑 `build-windows.bat` 出一个 exe 文件夹 | ImGui 桌面窗口 | 全部功能 |
| **Android** | Termux 里跑一条命令，浏览器打开 | 网页版（可装到主屏） | 全部功能 |
| **iOS** | Safari 打开电脑上跑的服务，「添加到主屏幕」 | 网页版 | 全部功能（算力在电脑上） |

> **为什么手机端不是原生 App**：这个工具的核心是 Python + UnityPy，解包要用到
> `lz4` / `brotli` / `texture2ddecoder` / `astc_encoder` / `etcpak` / `fmod_toolkit`
> 这些**原生扩展**。这些库没有 Android / iOS 的预编译轮子，也没有
> python-for-android 的现成 recipe。所以手机端走的是**网页版**（后端 Python
> 跑在 Termux 里 / 跑在电脑上），这是能真正跑起来的路。

---

## macOS

```bash
bash build-macos.sh
```

产物：

- `dist/口蘑Mod工坊.app` —— 拖进「应用程序」就能用
- `dist/口蘑Mod工坊.dmg` —— 40 MB，双击挂载后拖进去

**首次打开会被 Gatekeeper 拦**（没有 Apple 开发者签名）。解决办法：
右键点图标 → **打开** → 再点一次「打开」。只需要做一次。

命令行也能跑：

```bash
# 图形界面
dist/口蘑Mod工坊.app/Contents/MacOS/口蘑Mod工坊

# 网页版（不弹窗，起个本地服务）
dist/口蘑Mod工坊.app/Contents/MacOS/口蘑Mod工坊 --web --port 8765
```

## Windows

**PyInstaller 不能交叉编译** —— 在 macOS 上打不出 Windows 的 exe。
两个办法：

### 办法一：在 Windows 上双击 `build-windows.bat`

会自动建虚拟环境、装依赖、装 PyInstaller、打包。产物：

```
dist\口蘑Mod工坊\口蘑Mod工坊.exe
```

**整个 `dist\口蘑Mod工坊` 文件夹一起拷走**就能用（免安装，里面带着 Python 运行时）。

### 办法二：用现成的 exe

仓库里的 GitHub Actions 会在 Windows 机器上自动打包
（`.github/workflows/build.yml`，三个系统各跑一台）。在 Actions 页面下载
`pm-modkit-windows` 产物即可。

### 办法三：不打包，直接跑

装好 Python 3.10+ 后双击 `启动.bat` 就行（`setup.bat` 负责第一次装依赖）。

## Android

**用 Termux。** 网页版不依赖 imgui-bundle，Termux 里装得上。

```bash
# 1. 装 Termux（从 F-Droid 装，别用 Google Play 那个，版本太老）
# 2. 在里面依次跑：

pkg install -y git
git clone <本项目地址> && cd pm-modkit
bash android/termux-install.sh
```

装完启动：

```bash
bash android/termux-run.sh
```

它会起服务并打印地址，手机浏览器打开 **http://127.0.0.1:8765** 就是完整界面。

### 装成 App（推荐）

Chrome 里点右上角菜单 →「**添加到主屏幕**」。之后从桌面图标进去：
- 没有地址栏，全屏，跟 App 一样
- 界面外壳会缓存，启动很快
- 顶栏会出现「**装到主屏**」按钮，点它也有提示

同一个 Wi-Fi 下的电脑也能连：`http://<手机IP>:8765`。

## iOS / iPadOS

**iOS 上没法跑这个后端**（同上：原生扩展没有轮子，App Store 也不让装
Python 运行时）。所以正确的用法是：

**在电脑（或 Android 手机）上跑服务，用 iPhone/iPad 的浏览器连过去。**

```bash
# 在 Mac 上（默认就监听所有网卡）
dist/口蘑Mod工坊.app/Contents/MacOS/口蘑Mod工坊 --web --port 8765
# 或者
python3 web/server.py --port 8765
```

然后在 iPhone 上：

1. Safari 打开 `http://<电脑的局域网IP>:8765`
   （Mac 上查 IP：`ipconfig getifaddr en0`）
2. 点底部「**分享**」→「**添加到主屏幕**」
3. 桌面会出现「口蘑Mod工坊」图标，点开是全屏的，跟 App 一样

**算力在电脑上，手机只是显示和操作** —— 手机上拖进 APK、改数据、导出，
实际都是电脑在算，所以手机不会卡。

> 安全提醒：`--host 0.0.0.0` 是把服务开给整个局域网。
> 只在**自己家的 Wi-Fi** 上这么用，公共网络别开。

## 网页版（所有平台都能用）

任何能跑 Python 的地方：

```bash
python3 web/server.py --port 8765          # 只给本机
python3 web/server.py --port 8765 --host 0.0.0.0   # 给局域网（手机上用这个）
```

`requirements-web.txt` 里只有解析要用的库，**不装 imgui / numpy**，
所以在 Termux、树莓派、NAS 上都能跑。

网页版的功能跟桌面版一模一样：解包、改数据表、换贴图、新增条目、
完全新增角色、图鉴、体检、拖拽添加、导出、重打包 APK。

## 各平台的功能对照

| 功能 | macOS | Windows | Android | iOS |
|---|---|---|---|---|
| 打开 APK / 数据包 / 目录 | ✓ | ✓ | ✓ | ✓ |
| 拖拽添加文件 | ✓ 系统拖放 | ✓ 系统拖放 | ✓ 浏览器拖放 | ✓ 浏览器拖放 |
| 改数据表（中文字段名） | ✓ | ✓ | ✓ | ✓ |
| 换贴图 / 音频导出 | ✓ | ✓ | ✓ | ✓ |
| 新增条目 / 完全新增角色 | ✓ | ✓ | ✓ | ✓ |
| 角色图鉴 | ✓ | ✓ | ✓ | ✓ |
| 数据表体检 | ✓ | ✓ | ✓ | ✓ |
| 导出 .pmmod / UnityCache | ✓ | ✓ | ✓ | ✓ |
| 重打包 + 签名 APK | ✓ 需 JDK | ✓ 需 JDK | 受限 | 受限 |
| 装到主屏当 App | — | — | ✓ | ✓ |
| 离线可用 | ✓ | ✓ | 界面离线 | 界面离线 |

> **重打包 APK 需要 JDK + Android build-tools**（`apksigner` / `zipalign`）。
> 桌面端装上就有；手机上基本没有，所以导出时会自动退到
> **UnityCache / .pmmod** 路线 —— 那两条路本来就不需要重打包。

## 打包脚本一览

```
build-macos.sh          macOS：.app + .dmg
build-windows.bat       Windows：免安装的 exe 文件夹
android/termux-install.sh   Android：装依赖
android/termux-run.sh       Android：起服务
build/build_app.py      底层打包（PyInstaller），三平台共用
build/icon/             图标（png / icns / ico，四端共用一套）
.github/workflows/build.yml  三平台自动打包
```
